# Learning Resources

A collection of interactive learning guides covering AI technologies and interview preparation.

## 📚 Available Guides

### **LLM & Transformers** (`index.html`)
Learn about Large Language Models and Transformer architectures with interactive demos.

### **MCP & Agentkits** (`mcp.html`)
Comprehensive guide to the Model Context Protocol and building AI agents.

### **Presentation Mode** (`slides.html`)
Both LLM and MCP guides in a slide presentation format.

### **Quant Analytics Interview Prep** (`quant-analytics.html`)
Complete interview preparation guide for Senior Quantitative Analytics Associate roles. Covers SQL, Python, Statistics, ML, case studies, behavioral questions, and more.

## ✨ Features

- **Interactive Demos** - Hands-on learning with live visualizations
- **Professional Design** - Clean, modern interface with sidebar navigation
- **Mobile Responsive** - Works on all devices
- **No Dependencies** - Everything works offline
- **Multiple Formats** - Choose documentation or presentation mode

## 🚀 Quick Start

### Deploy to Vercel (Recommended)
```bash
npm install -g vercel
vercel
```

### Open Locally
Simply open any `.html` file in your browser, or run:
```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`
